Como o agente responde?
  1. Procura a pergunta no banco de dados SQLite (📚 Banco).
  2. Se não encontrar, consulta o agente de IA local (Ollama) (🤖 Agente IA).
  3. A resposta do agente é gravada no banco. Pergunte de novo e ela virá do banco!
  4. O agente lembra a conversa: depois de "Qual broca usar em concreto?", tente "e para metal?".
  5. Guardrails (🛡️) bloqueiam preço inventado, conselho perigoso e dados pessoais.
